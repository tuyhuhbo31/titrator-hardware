# Петли Rev12, ось М3×30

На две петли напечатать **по 2 экземпляра** каждого STL. STEP — те же детали в другом формате.
Петли находятся слева при взгляде спереди. Историческое имя стенки с их отверстиями — Side_Panel_Right.

Монтажные площадки 3 мм; наружный диаметр втулок 8 мм. Пакет втулок вдоль оси 22 мм.
Все проходные отверстия Ø3,2 мм, резьба — в металлических гайках.

Купить для двух петель: 2×М3×30 (оси), 8×М3×10 (монтаж), 12 гаек М3 и 12 шайб М3.
На каждую ось две шайбы по 0,5 мм и две обычные гайки высотой 2,4 мм; гайки законтрить,
сохраняя свободное вращение. Посадки и прочность требуют примерки на напечатанном образце.
Эти петли уже включены в общие STEP из 04_full_assembly.
