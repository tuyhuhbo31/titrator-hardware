# Как разместить проект на GitHub

## Новый репозиторий через браузер

1. Распакуй ZIP. Открой папку Titrator_GitHub_Ready: внутри лежит README.md и папки 01_body, 02_electrode и т. д.
2. Войди на https://github.com и открой https://github.com/new.
3. Repository name: например titrator-hardware. Description: «Корпус титратора, держатель электрода и петли: DXF, STEP, STL».
4. Выбери Public, если файлы должны видеть все, или Private, если доступ нужен только тебе/приглашённым.
5. Включи Add README, чтобы сразу появилась обычная страница репозитория. Нажми Create repository.
6. Нажми Add file → Upload files. Перетащи СОДЕРЖИМОЕ распакованной папки, включая папки и README.md.
   Загружаемый README заменит первоначальный. Сам ZIP вместо содержимого не загружай: иначе папки проекта не появятся.
7. Если файлов за один раз много, сначала загрузи README.md и GITHUB_UPLOAD_RU.md, затем по очереди папки
   01_body, 02_electrode, 03_hinges, 04_full_assembly и docs. Каждый раз начинай из корня репозитория.
8. В поле сообщения напиши Add enclosure and electrode CAD files и нажми Commit changes.
   В личном новом репозитории можно сохранить непосредственно в main.
9. Проверь папки, картинки и таблицу в README. Для скачивания всего проекта: Code → Download ZIP.

Пустые папки Git не сохраняет. Здесь каждая папка уже содержит файлы, поэтому отдельно создавать их не нужно.
Файл через веб-интерфейс ограничен 25 MiB. Каждый файл этого комплекта проверен на этот лимит.

## Если репозиторий уже есть

Открой его и создай, например, раздел hardware через Add file → Create new file:
в поле имени введи hardware/README.md, заполни краткое описание и нажми Commit changes.
Затем открой hardware, нажми Add file → Upload files и загрузи туда содержимое этого комплекта.
Если раздел hardware уже существует, сначала проверь, нет ли там одноимённых файлов: загрузка их заменит.

## Дальнейшие изменения

При обновлении детали замени соответствующий файл в папке и укажи понятное сообщение:
например Reduce pump lid width. GitHub сохранит предыдущую версию в истории.
Если меняешь размеры, обновляй одновременно DXF и STEP, общую сборку и таблицу деталей.
Не держи два разных актуальных варианта под одинаковыми названиями в разных папках.
